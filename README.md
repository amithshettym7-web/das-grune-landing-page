# 🌿 Das Grune — Creative Agency Landing Page

A modern and minimal creative agency landing page built using **HTML and CSS**.

## 📌 About The Project

Das Grune is a simple creative agency website focused on clean typography, modern layouts, large visual sections, and minimal design.

This project was created to practice and improve my **HTML and CSS** skills, especially:

* Flexbox
* CSS positioning
* Typography
* Background images
* Border radius
* Responsive layout concepts
* Remix Icon integration

## 🛠️ Technologies Used

* HTML5
* CSS3
* Remix Icon

## ✨ Features

* Modern navigation bar
* Large typography-based hero section
* Creative agency layout
* Image sections
* Play button
* Circular arrow button
* Minimal dark-themed design
* Clean and simple UI

1. Clone this repository:

